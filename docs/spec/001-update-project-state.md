作成日: 2026-10-29
ブランチ: feature/001-update-project-state

## 目的
`PROJECT_STATE.md` の最終更新は 2026-10-10 で、それ以降のコミットが反映されていない。
最新の状態に合わせる。あわせて、Claude → Codex の分担（指示書 → 実装 → 完了メモ → レビュー）が回るかを試す。アプリの動作は変えない。

## 変更するファイル
- 変更: `PROJECT_STATE.md`
- 新規: `docs/handoff/001-update-project-state.md`（完了メモ）
- 触らない: `src/`、`app/`、`package.json`、`app.json`、`legal-site/`、その他すべて

## 仕様
1. `git log --since=2026-10-10 --stat` で、2026-10-10 以降のコミットを調べる
2. `PROJECT_STATE.md` の次を、その内容に合わせて直す
   - 冒頭の「最終更新」の日付を 2026-10-29 にする
   - 「5. 実装済みの機能」に、まだ書かれていない機能（月次レポート、月初のバナー、購入情報の読み込みエラーコードなど）を追記する
   - 「8. 次にやること」のうち、コードを見て完了と確認できた項目に、既存の書き方にならって取り消し線と「完了」を付ける
3. 既存の文章のトーン・見出し・書式にそろえる。他の節は書き換えない
4. 事実だけを書く。コードやコミットから確認できないことは書かない。分からないことは、完了メモの「気になった点」に書く
5. `npx tsc --noEmit` を実行し、結果を完了メモに書く（エラーがあっても、直さず報告するだけにする）

## 決まっていること（変えない）
- 「2. 事業方針」「3. 設計上の重要判断」は一切変更しない
- `npm install` は実行しない

## やらないこと
- コードの修正、依存関係の追加・更新
- `git commit` と `git push`（コミットは Claude のレビュー後に、人が行う）

- 提案（指示書にない、やったほうがよいこと）
